# Product Designer Portfolio

A single-page (plus case-study sub-routes) portfolio for a product designer.
Editorial, dark, premium.

**Stack:** Next.js 14 (App Router) · TypeScript · Tailwind CSS · Framer Motion ·
React Three Fiber (Three.js) · Lenis smooth scroll.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
npm run lint
```

## Editing content

**All copy, projects, experience, testimonials, and links live in one file:**
[`data/content.ts`](./data/content.ts). No CMS — edit there and it flows through
the whole site.

### Projects & case studies

Each project's `link` supports both internal case studies and external links:

```ts
link: { type: "internal" }                      // renders /work/[slug]
link: { type: "external", href: "https://…" }   // opens in a new tab
```

Internal projects need a `caseStudy` object (Problem → Process → Solution →
Outcome + gallery). External projects skip it.

### Images

Placeholder art ships as self-contained local SVGs in `public/images/`
(generated by `node scripts/gen-placeholders.mjs`). Swap the `thumbnail` /
`hero` / `gallery` paths in `data/content.ts` for your own — drop files in
`public/` and reference them as `/my-image.jpg`.

### Booking / resume

- **Book a call** buttons use `site.bookingLink` (Cal.com link or a `mailto:`).
- **Resume** links use `site.resumeUrl` — replace `public/resume.pdf`.

## Effects & accessibility

- Smooth scroll (Lenis) and React Three Fiber are lazy-loaded (`ssr: false`) so
  they never block first paint; the 3D hero falls back to a gradient on
  touch/low-power devices and is wrapped in an error boundary.
- `prefers-reduced-motion` is respected globally — every animation has an
  instant-appear variant; 3D, parallax, custom cursor, and smooth scroll all
  disable when it's set.
- Custom cursor and tilt/magnetic effects are desktop-only.
- Semantic HTML, alt text, keyboard nav, visible focus; `next/image` for images.

## Design system

- **Fonts:** Fraunces (display) + Inter (body) via `next/font`.
- **Palette:** near-black base + single warm vermillion accent (`tailwind.config.ts`).
- Rounded cards (16–24px), soft borders, 8pt spacing.

## Deploy

Push to a Git repo and import in Vercel — framework preset **Next.js** is
auto-detected, no config needed.
